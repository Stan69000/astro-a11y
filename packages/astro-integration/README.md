# @astro-a11y/astro-integration

Astro integration that scans every built page (including pages generated by dynamic routes) with Playwright + axe-core, maps findings to RGAA 4.1 criteria and writes HTML, JSON and Markdown reports.

```bash
pnpm add -D @astro-a11y/astro-integration
npx playwright install chromium
```

```js
// astro.config.mjs
import { defineConfig } from 'astro/config';
import astroA11y from '@astro-a11y/astro-integration';

export default defineConfig({
  integrations: [astroA11y({ mode: 'balanced' })]
});
```

Reports are written to `dist/astro-a11y/`. Options, modes and limits: see the [main documentation](https://github.com/Stan69000/astro-a11y#readme) ([français](https://github.com/Stan69000/astro-a11y/blob/main/README.fr.md)).
