# @astro-a11y/core

Scanning engine behind [astro-a11y](https://github.com/Stan69000/astro-a11y): Playwright + axe-core, RGAA 4.1 mapping, remote-target security guards and the shared failure policy.

Most users want the [CLI](https://www.npmjs.com/package/astro-a11y) or the [Astro integration](https://www.npmjs.com/package/@astro-a11y/astro-integration) instead.
